# Job Search Strategy 🔒 (starts week 12)

Applications are on hold until the plan is done. This file is ready for then.

## Where to look

| Site | Best for | Tip |
|---|---|---|
| LinkedIn Jobs | Most roles; recruiters search here | Turn on "Open to work" (recruiters only); set job alerts for each target title + London/Remote UK |
| Indeed UK | Volume, smaller firms | Upload the .docx resume so parsing works |
| Reed | UK agencies and permanent roles | Agencies call quickly; keep your phone answer ready |
| CWJobs | Tech-only roles | Good for QA Automation and SDET titles |
| Company career sites | Banks, insurers, fintechs | Apply directly; it often skips the agency filter |
| ITJobsWatch | Salary and demand research | Not for applying; check medians before negotiating |

**Target employers (domain fit):** UK banks and building societies, insurers, payment firms and fintechs, and consultancies that test for them.

## Weekly rhythm (from week 12)

- 5–8 tailored applications a week beat 40 generic ones.
- Every application gets the job description analysis below, saved under `Applications/<company>/`.
- Track everything in one spreadsheet: company, role, date, source, status, next step.

## Job description analysis template

Paste an advert and fill in:

```
Company / Role / Location / Salary:

MUST-HAVE requirements          | My evidence (work or link)         | Status
--------------------------------|------------------------------------|--------
1.                              |                                    | ✅ / 🟡 learning / ❌
2.
3.

NICE-TO-HAVE requirements       | My evidence                        | Status

ATS keywords (exact phrases from the advert, to use in my resume where true):

Suitability: (count of must-haves with ✅) / (total must-haves) = __%
  - 80%+: apply with confidence
  - 60–79%: apply, and address the gap in the cover letter
  - under 60%: skip, unless the company trains juniors

Likely interview topics:
Preparation needed (link to 08-interview-prep.md sections):
```

The suitability score is deliberately simple and transparent: it only counts requirements I can prove.

## ATS keyword bank for UK QA adverts

Use only the ones that are true for me: Test Automation, Selenium WebDriver, Java, TestNG, Page Object Model, REST Assured, API Testing, Postman, SQL, Playwright, TypeScript, CI/CD, GitHub Actions, Jenkins, Agile, Scrum, Regression Testing, Test Strategy, Defect Management, Jira, Azure DevOps, BDD/Cucumber (only after learning it), Docker, Accessibility (WCAG), Banking, Payments, Financial Services, ISTQB, LLM Testing, AI Evaluation.
